## 1. 整体架构与系统设计

### 1.1 系统架构概览

```
┌─────────────────────────────────────────────────────────────┐

│ │   渲染进程           │          │    主进程             │  │

│         │ localStorage             │ SQLite               │  │
│         │ Redux State              │ LanceDB              │  │
└─────────────────────────────────────────────────────────────┘
          │                              │
          │ HTTP/HTTPS                   │
          ▼                              ▼
┌──────────────────────────────────────────────────────────┐
```

### 2.2 Electron 风险点

| 风险 | 原因 | 排查方法 |
|------|------|---------|
| Native 模块不兼容 | 32/64 位不匹配、VC运行时缺失 | 检查 build output 的 .node 文件 |
| autoUpdater 失败 | 更新服务器地址错误或权限问题 | 检查 electron-updater 日志 |
| SQLite 路径错误 | 跨平台路径不一致 | 检查 `app.getPath()` 的返回值 |
| preload.js 注入风险 | IPC 通道未验证 | 检查 preload 中是否有敏感权限暴露 |

### 紧急情况处理

1. **应用无法启动**
   - 检查日志：`pm2 logs moi-ai --err`
   - 检查环境变量：`.env` 文件是否存在且完整
   - 检查端口占用：`netstat -a | grep :3000`

2. **数据库连接失败**
   - 检查 SQLite 文件权限
   - 检查磁盘空间
   - 检查 TypeORM 配置

3. **服务崩溃恢复**
   - 停止所有进程：`pm2 stop all`
   - 恢复备份：从备份恢复数据文件
   - 重启服务：`pm2 start moi-ai`
